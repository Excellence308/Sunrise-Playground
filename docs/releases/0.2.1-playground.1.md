# Sunrise Playground 0.2.1-p1 — Subclasses

Tag: `0.2.1-playground.1`

Status: **experimental prerelease**

This is an independent reverse-engineering playground build based on Sunrise 0.2.1 and the
TotalTaxAmount Linux fork. It is not an official release from either project. Their work made this
experiment possible.

## Included

- Merged the upstream inventory-functionality work from pull request 18.
- Preserved the displaced item's inventory position during equipment swaps.
- Added authored startup defaults for keybind storage, VSync, field of view, video settings, and
  keybindings used by this Linux setup.
- Added all three installed subclass items for Hunter, Titan, and Warlock.
- Added runtime ability acquisition and selection, including correct acquired/active visual state.
- Stored ability choices per subclass item while the game is running, so swapping subclasses
  restores that subclass's own selections.
- Expanded the fixed ability-definition storage from 256 to 512 rows for all nine installed
  subclass socket-entry lists.
- Resolved alternate-super selectors from installed package data instead of hardcoding a class,
  tree, or ability hash.

## Verified

- Linux launch through the project's Proton/UMU setup.
- Inventory equipment swapping and displaced-item ordering.
- Hunter Gunslinger node acquisition, selection, unselection visuals, and Blade Barrage tree
  selection.
- All three Warlock subclass items appear and their nodes can be acquired.
- Attunement of Grace publishes the Well of Radiance HUD icon and casts Well of Radiance in an
  activity.

## Not claimed

- The other eight supers have not each been individually cast-tested.
- Account, character, and subclass mutations are session state. A restart reapplies the authored
  startup configuration; this release does not add a persistent account database.
- Missions, enemies, NPCs, quests, and a completed Tribute Hall are not part of this release.
- The Tribute Hall roster-schema experiment is intentionally excluded from this release binary.

## Installation boundary

Use only with the old Shadowkeep game build required by Sunrise and follow the upstream Sunrise
installation documentation. You must provide your own game files.

1. Close Destiny 2 completely.
2. Back up the existing `bin/x64/steam_api64.dll`.
3. Replace it with the Linux x64 DLL from this release.
4. Launch using the same offline Sunrise Linux launcher you already configured.

The first launch may rebuild Sunrise's extracted build-data cache. Do not use this DLL with the
current live Destiny 2 installation or Bungie services.

No game data is included in the release.
